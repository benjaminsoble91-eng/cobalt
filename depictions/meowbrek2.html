meowbrek2 — no palera1n

no computer · no Safari method

About

Jailbreak an iOS 15 device straight from the device. TrollInstallerX installs TrollStore, TrollStore installs meowbrek2, and meowbrek2 sets up the jailbreak (bootstrap + Sileo) by itself. After every reboot, open meowbrek2 and tap Jailbreak again.

Check first

Settings > General > About must say iOS 15.0 – 15.8.x (A9–A11; A8 only on 15.0–15.1). On iOS 16 this doesn't work: meowbrek2 is iOS 15 only.

Rootful palera1n or an old rootless palera1n install has to be removed first.

1Install TrollStore

Sideload TrollInstallerX with your Apple ID (Benstore, Sideloadly, AltStore…). Open it and tap Install TrollStore. If it gets stuck at "Exploiting kernel", reboot and try again. Pick a removable app (like Tips) when it asks for the persistence helper.

Download TrollInstallerX .ipa Source code (alfiecg24, MIT)

2Install meowbrek2

In TrollStore, open Settings and turn on URL Scheme Enabled. Then tap the button below. It opens TrollStore and installs meowbrek2 1.1.7 from the developer's official link.

Get meowbrek2 in TrollStore Or download the .tipa (open it in TrollStore with +)

3Jailbreak

  1. Reboot (recommended).
  2. Open meowbrek2 right away and tap Jailbreak.
  3. First run installs the bootstrap; Sileo shows up on the Home Screen.
  4. If it crashes or reboots, reboot and run it again. kfd doesn't win every time.

Good to know

  • meowbrek2 is by dora2ios and is closed source. TrollInstallerX and TrollStore are open source.
  • Rootless jailbreak: tweaks for rootless (iphoneos-arm64) work.
  • Have a computer handy? Rootless palera1n (checkm8) can still act as a backup anytime.
