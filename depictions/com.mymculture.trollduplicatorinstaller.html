TrollDuplicator Installer

com.mymculture.trollduplicatorinstaller

About

Installs TrollDuplicator through TrollStore, then removes itself. When it's done, only TrollDuplicator is left on your device.

How it works

  1. Install TrollDuplicator Installer from Cobalt.
  2. It hands TrollDuplicator to TrollStore's installer, so the app is a normal TrollStore app.
  3. As soon as Sileo finishes, the installer package removes itself.
  4. Open TrollDuplicator from the Home Screen.

Good to know

  • Needs TrollStore (or Trollamine) installed, with ldid.
  • If the install fails, the installer stays so you can reinstall it and try again.
  • Removing the installer never removes TrollDuplicator.
