Benstore Installer

com.mymculture.benstoreinstaller

About

Installs Benstore, the on-device sideloader, through TrollStore, then removes itself. Installed this way Benstore never expires: no 7-day refresh for Benstore itself, and no Mac needed to set it up.

No TrollStore? It installs Benstore as a jailbreak app instead and stays installed, so uninstalling it removes Benstore too.

How it works

  1. Install Benstore Installer from Cobalt.
  2. It hands Benstore to TrollStore's installer, so the app is a normal TrollStore app.
  3. As soon as Sileo finishes, the installer package removes itself.
  4. Open Benstore, sign in with your Apple ID, and connect LocalDevVPN to start installing apps.

Good to know

  • The apps Benstore installs are still signed with your Apple ID, so they keep the usual 7-day refresh and 3-app limit. Only Benstore itself stops expiring.
  • Benstore still needs LocalDevVPN connected to install and refresh apps.
  • To update a TrollStore or jailbreak copy, install the newest Benstore Installer from Cobalt. Its version always matches the Benstore it installs.
  • Already have Benstore from the Mac installer? This replaces it with the TrollStore copy.
  • If the install fails, the installer stays so you can reinstall it and try again.
