PanicButton

com.mymculture.panicbutton

About

PanicButton triggers a true kernel panic from Settings. The phone reboots immediately and a full panic-full log is saved to Settings → Privacy & Security → Analytics & Improvements → Analytics Data.

Read this first

  • The phone reboots immediately. Save anything open.
  • Dopamine is semi-untethered, so you boot to stock. Re-jailbreak afterwards.
  • No data is lost. iOS journals the filesystem.
  • Works only while jailbroken with Dopamine on A9 devices (iPhone 6s, iPad Pro 9.7).

How it works

  1. A suid-root helper loads Dopamine’s libjailbreak.
  2. It acquires kernel read/write from the jailbreak server.
  3. It writes to an unmapped kernel address, triggering a data-abort panic.

The panic log contains the full register state and backtrace.

How to use

  1. Install PanicButton from Cobalt.
  2. Open Settings → PanicButton.
  3. Tap Trigger Kernel Panic and confirm.
