meowbrek2 Installer

com.mymculture.meowbrek2installer

About

Sets up meowbrek2 by dora2ios on a device jailbroken with rootless palera1n. After that, you re-jailbreak from an app after every reboot instead of plugging into a computer.

No TrollStore yet? It installs TrollStore first from a copy bundled in the package, so you don't need the Safari / TrollHelperOTA method.

How it works

  1. Jailbreak once with palera1n in rootless mode (palera1n -l).
  2. Add Cobalt in Sileo and install meowbrek2 Installer.
  3. It installs TrollStore if needed, then installs meowbrek2 through TrollStore, then removes itself.
  4. After a reboot, open meowbrek2 right away and tap Jailbreak.

Good to know

  • meowbrek2 uses the kfd exploit, not checkm8. It brings back your palera1n jailbreak (bootstrap, Sileo, tweaks). palera1n still works as a backup anytime.
  • iOS 15 only, A11 and older, rootless palera1n only. Rootful palera1n has to be removed first.
  • Downloads meowbrek2 1.1.7 from the developer's site while installing, so stay on Wi-Fi.
  • If meowbrek2 crashes or reboots the device, reboot and run it again.
  • Recommended: TrollStore > Settings > Install Persistence Helper.
  • If anything fails, the installer stays so you can reinstall it and try again. Log: /var/tmp/meowbrek2installer.log
